# Feierabend — Decke 01

Concept landing page for a German-mill, zero-polyester wool blanket built for tech workers.
Single self-contained HTML file (all images embedded as WebP data URIs, no build step, no dependencies).

**Live site:** https://maniwar.github.io/Blanket/

- Fonts: Gloock · Hanken Grotesk · IBM Plex Mono (Google Fonts)
- Effects: scroll-scrubbed hero zoom, pinned word-reveal statement, parallax image breaks, sticky benefit photo stack, curtain clip-path reveals
- Fully responsive, `prefers-reduced-motion` respected
