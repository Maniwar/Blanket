The handbook

Procedures

Standard operating procedures — the concierge follows these exactly. It can read the register on its own; for signed-in owners it can also change a shipping address (before shipment) and cancel unshipped orders. Write procedures the way you would brief a careful new hire.

Conversation goals

what every conversation should accomplish

The concierge pursues these in every conversation, and each conversation is scored against them — see met / partial / unmet on the Conversations tab. Edit the label and description; disable any you don't want pursued.

Forms

structured input the concierge can hand out

Each form renders inside the chat when the concierge emits its token. Fields are JSON: name, label, type (text · state · zip), required, maxlength, autocomplete. Submissions run through the same verified, audited write path as the concierge's own tools.
